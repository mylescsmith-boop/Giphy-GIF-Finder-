# Assignment #9 - Giphy GIF Finder

A simple GIF search page built with HTML, CSS, Bootstrap, and JavaScript.

## How to run it
1. Open the repository in VS Code.
2. Open `js/script.js`.
3. Replace `YOUR_GIPHY_API_KEY` with your own GIPHY API key.
4. Save the file and open `index.html` with Live Server.
5. Search for a word or phrase to display GIF results.

Keep your API key private. Do not post it in a public repository or share it in a chat.

## Project files
- `index.html` contains the page and search form.
- `css/style.css` styles the page and GIF results.
- `js/script.js` calls the GIPHY API, stores image URLs in an array, and displays results.
